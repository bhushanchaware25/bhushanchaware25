## 🚀 Featured Projects

### 🔹 [Natural Language to SQL Agent](https://github.com/bhushanchaware25/NL-SQL-Agent)
`LangChain` `LangGraph` `ChromaDB` `PostgreSQL`
5-agent autonomous LangGraph pipeline (Schema Inspector → SQL Generator → Executor → Critic Validator → Response Synthesizer) that converts natural language into PostgreSQL queries, with self-healing retry logic, ChromaDB few-shot RAG, a two-layer SQL Safety Guard (Regex + AST via sqlparse), and a real-time React/WebSocket frontend with live agent reasoning traces and Recharts visualizations.

### 🔹 [Autonomous Research Agent](https://github.com/bhushanchaware25/Research-Agent)
`Python` `LangChain` `LangGraph` `Streamlit` `Pydantic`
Five specialized agents (query decomposition, web research, synthesis, critique, report writing) wired into a self-correcting LangGraph pipeline that produces cited, publication-ready research reports, with a Critic-driven feedback loop for dynamic Tavily search iterations and Pydantic-validated structured outputs.

### 🔹 [RAG Chatbot — Local LLM System](https://github.com/bhushanchaware25/rag-project)
`Ollama` `ChromaDB` `LangChain` `Streamlit`
Fully CPU-bound, offline RAG pipeline for private document Q&A — multi-format ingestion (PDF, DOCX, TXT, URLs), semantic vector search with ChromaDB, and a dual Streamlit + CLI interface with logging and a retrieval test suite.
